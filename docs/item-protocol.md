## 응답 규약: 사안 분리

사용자는 응답을 사안 카드로 나눠 보고, 카드마다 따로 처리해 한 번에 답한다. 그래서 응답은 사용자가 결정할 단위로 나눠 쓴다.

```
전체 흐름을 짚는 종합 의견. 1~5줄, 필요할 때만

### [제안] 합산 시 가격은 새 값으로 덮어쓰기 (← #1S-2-3)
해 본 결과, 근거, 선택지, 영향
```

- 종류
  - [질문]: 사용자의 판단이나 정보가 있어야 진행할 수 있는 것
  - [제안]: 승인을 받고 진행하려는 것
  - [보고]: 한 일과 알게 된 사실. 확인만 받으면 되는 것
- 사안 하나에는 결정 하나를 담는다. 제목만 읽어도 무엇을 결정하는지 알 수 있게 쓰고, 근거와 선택지는 본문에 쓴다
- 지시를 수행한 결과와 그에 따른 제안은 한 사안에 함께 쓴다. 결정할 것이 있으면 그 사안을 [제안]이나 [질문]으로 쓴다
- 이전 사안에서 이어진 사안은 제목 끝에 출처 `(← #ID)` 를 붙인다. 한 사안에서 결정이 여럿 나오면 각각 같은 출처를 붙인다
- 응답은 마지막 사안의 본문으로 끝낸다
- 짧은 물음에 답할 때는 [보고] 하나로 쓴다
- 맡은 일이 끝나 처리할 사안이 더 없으면 다음 할 일을 묻는 [질문] 하나를 쓴다. 정리할 시점이면 `/clear` 를 권하는 [제안] 하나를 쓰고, 남길 결정은 [D], [W] 로 함께 올린다

## 사용자 답장

사안마다 `#1S-2-3 [제안] 제목 → 승인: 덧붙인 말` 처럼 한 줄로 온다. 사안 ID 는 `<세션>S-<턴>-<순번>` 이고 /clear 마다 세션 번호가 오른다. 받은 ID 를 그대로 옮겨 쓴다. 처리는 답변, 승인, 수정, 보류, 기각, 확인이다. 덧붙인 말 없이 확인한 사안은 `확인: #ID, #ID 사안 종료됨.` 한 줄로 묶여 온다.

- 확인으로 끝난 사안은 응답에서 다루지 않고 다음 일로 넘어간다. 확인에 덧붙인 말이 있으면 그 말에만 답한다
- 승인에 덧붙인 말은 조건으로 반영해 진행한다
- 수정을 받은 사안은 수정안을 반영한 [제안]을 출처 `(← #ID)` 를 붙여 다시 올린다. 방향은 받아들여진 것이다
- 기각된 사안은 사유를 반영하고 다른 방향을 찾는다. 제안하기 전에 `overseer` 도구 `decisions` (action "reject")로 비슷한 제안이 기각된 적이 있는지 본다
- 보류된 사안은 사용자가 다시 꺼낼 때까지 손대지 않는다

사용자가 모듈 패널(ln 모듈 지도)에서 한 일은 같은 메시지에 이런 줄로 온다.

- `[책임 수정] l1.cli_io: 새 책임` → 그 모듈의 layerinfo 책임 한 줄을 그대로 바꾼다. 지금 코드가 그 책임과 어긋나면 [보고]나 [제안]으로 올린다
- `[모듈 질문] l1.cli_io: 물음` → 그 모듈에 대한 물음이다. [보고]로 답한다
- `[새 책임 카드] 이름: 책임` → 사용자가 맡기려는 책임이다. 이름은 없을 수 있다. 타당성 분석과 함께 이름과 경계, 놓을 층, 공용 모듈 사용, 하위 구성을 [제안]으로 올린다. 승인 전에는 만들지 않는다
- 책임 한 줄은 그 모듈이 무엇을 맡는지 쓴다. 어떻게 하는지(기능, 처리 단계, 함수 이름)는 쓰지 않는다

## 보존 사안: [D] 결정 기록, [W] 용어

다음 세션에도 유효한 결정과 용어는 보존 사안으로 올린다. 사용자가 승인하면 패널이 보존하고, 세션을 시작할 때마다 목록으로 넣어 준다. 목록이 매번 들어가니 꼭 필요한 것만 짧게 올린다.

- 기준: 이 기록이 없으면 다음 세션이 다르게 판단하거나 사용자에게 다시 물을 것만 올린다
- 남길 만한 것: 코드에 드러나지 않는 방침. 다른 프로젝트와의 약속, 하지 않기로 한 것, 일부러 그대로 둔 것
- 올리지 않는 것
  - 코드, CLAUDE.md, 문서에 이미 있거나 이번 세션에 적은 것
  - 구현 세부: 수치, 배치, 로그 수준, 파일 위치
  - 이미 굳은 구조, 일반 프로그래밍 상식
- [W] 는 이 프로젝트에서 뜻이 달라지거나 헷갈린 적 있는 이름만 올린다. 보통 낱말은 올리지 않는다
- 한 번에 [D], [W] 합쳐 3개 이내로 올린다. 올릴 것이 없으면 [보고] 로 "남길 기록 없음" 을 쓴다

```
### [제안][D] 같은 이름 재추가 시 수량은 합산, 가격은 새 값으로
근거: #1S-2-2
대체: D-3
```

- [D] 제목: 결정 한 줄, 60자 이내. 이유는 근거 사안에 있으니 결정만 쓴다
- [W] 제목: `용어: 뜻`, 뜻은 20자 안팎
- `근거:` 에는 사용자가 실제로 결정한 사안 ID 를 쓴다. 사용자가 결정한 것만 올린다
- 받은 목록과 다르게 정하려면 `대체: <기록 ID>` 를 붙여 올린다
- 보존은 패널이 맡는다. 승인된 기록은 패널에만 두고, CLAUDE.md 나 메모리에는 옮겨 적지 않는다
- 기록의 이력과 근거는 `overseer` 도구 `record`, 목록과 검색은 `records` 로 본다
