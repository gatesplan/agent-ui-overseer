## 응답 형식: 사안 분리

사용자가 처리해야 할 내용은 사안 단위로 나눠 쓴다. 사용자는 사안마다 따로 답변·보류·기각한다.

각 사안은 아래 형식의 제목으로 시작한다.

```
### [질문] 한 줄 제목
### [제안] 한 줄 제목
### [보고] 한 줄 제목
```

- [질문]: 사용자의 판단이나 정보가 있어야 진행할 수 있는 것
- [제안]: 사용자 승인을 받고 진행하려는 것
- [보고]: 수행한 일, 발견한 사실. 확인만 받으면 되는 것
- 한 사안에는 결정 하나만 담는다. 결정이 여럿 섞이면 사안을 나눈다
- 제목은 그것만 읽어도 무엇을 결정하는지 알 수 있게 쓴다. 근거, 선택지, 영향은 제목 아래 본문에 쓴다
- 이전 사안에서 파생된 사안은 제목 끝에 출처를 붙인다: `### [질문] 합산 시 가격 처리 (← #1-4)`
- 종합 의견은 응답 맨 앞, 첫 사안 제목 위에 다섯 줄 이내로 쓴다. 사용자 화면에서 종합 의견 카드로 따로 보인다
- 마지막 사안 뒤에는 맺음말을 쓰지 않는다
- 처리할 것이 없는 짧은 대답이면 [보고] 하나로 쓴다

사용자 답장은 `#ID 답변: ...`, `#ID 기각: 사유`, `#ID 보류`, `#ID 확인` 형식으로 온다.

- 기각된 사안은 사유를 반영하고, 같은 내용을 다시 제안하지 않는다
- 보류된 사안은 진행하지 않는다. 사용자가 다시 꺼낼 때까지 그대로 둔다

## 보존 사안: 결정 기록 [D], 용어 [W]

다음 세션에도 유효한 결정과 용어는 보존 사안으로 올린다. 종류 라벨 뒤에 `[D]`(결정 기록), `[W]`(용어)를 붙인다.

```
### [제안][D] 같은 이름 재추가 시 수량은 합산, 가격은 새 값으로
근거: #2-2
대체: D-3

### [제안][W] 사안: 사용자가 따로 결정하는 단위
근거: #1-4
```

- [D] 제목은 결정 한 줄, 60자 이내. 이유와 자세한 내용은 근거 사안에 있으니 쓰지 않는다
- [W] 제목은 `용어: 뜻` 한 줄. 뜻은 20자 안팎
- `근거:` 줄에 사용자가 실제로 결정한 사안 ID 를 붙인다. 사용자가 결정하지 않은 것은 올리지 않는다
- 이미 있는 기록과 어긋나면 `대체: <기록 ID>` 를 붙인다. 기록 ID 는 세션 시작 때 받은 목록의 `D-3`, `W-1` 같은 번호다
- 사용자가 승인하면 패널이 보존하고 다음 세션 시작 때 목록으로 넣어 준다. 승인된 기록을 CLAUDE.md 나 다른 문서에 직접 옮겨 적지 않는다
- 세션 시작 때 받은 목록의 결정과 용어를 따른다
